# SillyTavern 聊天工具箱

面向 SillyTavern 当前聊天的第三方扩展，提供查找替换、世界书管理、小剧场、AI 词句修改、预设条目转移和文本导出。

## 功能

- **查找/替换**：按楼层导航，支持书签、普通文本和正则查找；修改内容先暂存在工具箱中，确认后再写回聊天。
- **世界书管理**：读取、创建、重命名、删除和编辑世界书；可调整条目状态、位置、深度、顺序、关键词和内容。
- **小剧场**：选择酒馆预设、世界书条目和聊天上下文后生成独立内容；支持跟随酒馆主接口或使用自定义渠道、流式传输、并行任务、取消任务、结果收藏和放大阅读。
- **词句修改**：选择聊天楼层后逐段修订词句，审核每段结果并按原文位置替换。
- **预设条目转移**：编辑单个预设，或在两个预设之间复制、移动和排序提示词条目。
- **文本导出**：按楼层范围、正文标签和发言者筛选，导出 TXT 或 EPUB。

## 设置保存

会保存以下内容：

- 自定义 API 渠道
- 词句修改的生成渠道、内置提示词、用户规则和规则预设
- 小剧场的生成渠道、内置提示词、小剧场预设、世界书选择预设和收藏

楼层号、普通勾选项、搜索条件和界面展开状态只在当前页面中保留，刷新后清空。

## 小剧场生成渠道

- **跟随酒馆主接口**：使用酒馆当前连接、模型、流式设置和回复上限。
- **自定义渠道**：严格使用工具箱中填写的接口地址、模型、温度、最大输出和流式开关。

小剧场结果会按模型返回内容显示，不会根据 `<think>`、分析文字或 `<div>` 外文字自动删减。需要的输出格式请直接写在内置 system 提示词中。

## 安装

1. 在 SillyTavern 顶部打开“扩展”（Extensions）。
2. 选择“安装扩展”（Install Extension）。
3. 粘贴仓库地址：`https://github.com/c09222364-boop/Chat-toolbox`
4. 完成安装后刷新 SillyTavern。
5. 从三条杠菜单底部打开“聊天工具箱”。

扩展的各项功能可以在 Extensions 设置中单独开关。

## 使用建议

- 查找替换时先查找并逐项确认，完成后再点击“保存修改”。
- 世界书和预设条目在工具箱中编辑后，需要点击对应的保存按钮才会写入文件。
- 词句修改和小剧场在生成前都可以查看实际发送预览及总字数。
- EPUB 正文标签填写 `content` 时，会读取每层 `<content>...</content>` 内的文字。
