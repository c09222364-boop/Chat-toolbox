# SillyTavern 聊天工具箱

面向 SillyTavern 当前聊天的原生第三方扩展，同时保留 Userscript 兼容入口。所有设置（API 通道、规则预设、功能开关、小剧场收藏）保存在酒馆扩展设置或浏览器缓存中，不写入聊天记录。

## 功能

工具箱入口会同时出现在 SillyTavern 三条杠菜单底部和 Extensions 设置中。Extensions 中可以逐项关闭暂时不用的功能，菜单入口仍会保留。

- **查找/替换**：楼层导航、书签、正文 `mes`、发言者 `name`、完整消息 JSON 三种范围；普通文本/正则查找；集中滚动结果与命中高亮；逐条替换、整体替换、去除多余空行；修改先暂存在内存，点击“保存修改”后一次写回。
- **文本导出**：TXT 与 EPUB 导出，支持按楼层范围、正文标签和发言者筛选。
- **词句修改**：选择 AI 楼层和正文标签，调用生成渠道做词句修订；逐段审核后按原文字符范围原位替换，异常的多段 replacement 会被阻止写入。
- **段落改写**：按段落生成候选，逐段采用/忽略；可选择角色卡、用户设定、最近上下文和具体世界书条目。
- **小剧场**：独立生成 IF 线、角色想法和幕后片段，不插入聊天楼层；最近结果可临时保留、收藏、删除，并支持放大阅读。
- **世界书管理**：读取、创建、重命名、删除世界书；以圆形状态灯控制蓝灯/绿灯和启停，展开条目编辑，编辑模式下批量新建、当前书内复制或删除；关闭时可选择保存并退出、不保存退出或取消继续编辑。
- **预设条目转移**：支持单预设内部编辑与双预设复制/移动；放置方式精简为列表开头或所选条目后；可切换加载全部/仅加载已启用，条目内容按需折叠展开，同名差异条目可在对比区直接编辑保存。
- **API 与预设**：多个 OpenAI 兼容渠道、拉取模型、温度/最大输出和规则预设均保存在插件设置中。

## 安装

### SillyTavern 原生扩展（推荐）

1. 确保运行 SillyTavern 的设备已经安装 Git。
2. 在 SillyTavern 顶部打开“扩展”（Extensions）。
3. 选择“安装扩展”（Install Extension）。
4. 粘贴仓库地址：`https://github.com/c09222364-boop/Chat-toolbox`
5. 按需选择“当前用户”或“所有用户”，完成安装后刷新 SillyTavern。
6. 在三条杠菜单底部点击“聊天工具箱”，也可以从 Extensions 设置开启或关闭各功能。

后续版本可以在“管理扩展”中更新，无需重新复制脚本。

如果以前已经通过 Tampermonkey 或 Violentmonkey 启用了本脚本，请先禁用 Userscript 版本，避免同一个工具箱被重复加载。

### Userscript 兼容安装

如果使用的 SillyTavern 环境无法安装第三方扩展，也可以安装 Tampermonkey、Violentmonkey 等 Userscript 管理器，打开 [聊天工具箱.user.js](./聊天工具箱.user.js)，复制全部内容到新建脚本中并保存。

## 使用建议

- 查找替换时先点击“查找”，再逐条替换；全部调整完成后点击“保存修改”，避免重复写入聊天文件。
- 世界书和预设条目操作都先在界面中选择和编辑，再使用明确的保存/复制/移动按钮确认。
- 段落改写和小剧场可在调用前预览实际发送内容；世界书必须手动勾选具体条目，不会自动发送整本书。
- EPUB 的正文标签填写 `content` 时，会自动读取每层 `<content>...</content>` 内的文字。
