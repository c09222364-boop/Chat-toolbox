# SillyTavern 聊天工具箱

用于 SillyTavern 当前聊天的 Userscript，集中提供楼层导航、查找替换、聊天导出与 AI 辅助改写。

## 当前版本

- 当前稳定版：**v0.7.0**
- 安装文件：[聊天工具箱.user.js](./聊天工具箱.user.js)
- 版本归档：[versions/v0.7.0/聊天工具箱-v0.7.0.user.js](./versions/v0.7.0/聊天工具箱-v0.7.0.user.js)
- 上一版本：[versions/v0.6.0/聊天工具箱-v0.6.0.user.js](./versions/v0.6.0/聊天工具箱-v0.6.0.user.js)

> 本仓库只收录“聊天工具箱”。八股探针、独立的聊天查找与替换插件不在本仓库中。后续版本会继续放在 `versions/` 目录。

## 功能

- 从 SillyTavern 菜单打开工具箱，支持手机端居中显示。
- 楼层跳转、书签与关键词搜索。
- 正文 `mes`、发言者 `name`、完整消息 JSON 三种查找范围，支持普通文本与正则。
- 查找结果集中滚动展示、命中高亮、点击跳转楼层。
- 查找替换先暂存在内存中，支持逐条替换、整体替换、撤销上次替换、去除多余空行，最后一次性保存。
- TXT 与 EPUB 导出，可按正文标签提取内容。
- AI 词句修改：选择楼层与正文标签，调用可配置的模型通道处理正文。
- 段落改写：按段落生成候选结果，逐段审核后采用，支持上下文、角色卡、用户设定和已选世界书条目。
- API 通道设置、模型列表、修改规则预设均保存在浏览器/插件设置中，不写入聊天记录，也不会提交到仓库。

## 安装

1. 安装 Tampermonkey、Violentmonkey 等 Userscript 管理器。
2. 打开 [聊天工具箱.user.js](./聊天工具箱.user.js)，复制全部内容到新建脚本中并保存。
3. 在 SillyTavern 的左侧菜单底部点击“聊天工具箱”。

如果直接使用 Raw 链接，请确保当前 GitHub 会话有权限访问这个私人仓库。

## 使用建议

- 查找替换：先执行查找，再逐条替换；全部调整完成后点击“保存修改”，避免每次替换都触发聊天文件写入。
- AI 功能：先在“API 设置”中拉取模型并选择通道，再保存规则预设；正式采用前建议先预览发送给模型的提示词。
- 导出：正文标签填写 `content` 时，会自动提取每层 `<content>...</content>` 内的正文。
