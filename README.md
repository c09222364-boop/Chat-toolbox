# SillyTavern 聊天工具箱

面向 SillyTavern 当前聊天的第三方扩展，提供查找替换、世界书管理、临时 IF 支线、AI 词句修改、预设条目转移和文本导出。

## 功能

- **查找/替换**：按楼层导航，支持书签、普通文本和正则查找；修改内容先暂存在工具箱中，确认后再写回聊天。
- **世界书管理**：读取、创建、重命名、删除和编辑世界书；可调整条目状态、位置、深度、顺序、关键词和内容，并模拟最近 2 层会触发的条目。
- **IF 支线**：从开场词库建立临时 user 指令，直接使用酒馆原生聊天连续对话；结束时可收藏并删除整条支线、仅删除，或保留为正式主线。
- **词句修改**：选择聊天楼层后逐段修订词句，审核每段结果并按原文位置替换。
- **预设条目转移**：编辑单个预设，或在两个预设之间复制、移动和排序提示词条目。
- **文本导出**：按楼层范围、正文标签和发言者筛选，导出 TXT 或 EPUB。

## 设置保存

会保存以下内容：

- 自定义 API 渠道
- 词句修改的生成渠道、内置提示词、用户规则和规则预设
- IF 开场词库和支线收藏夹

进行中的 IF 支线会把起点和开始前的变量快照保存在当前聊天元数据中，以便刷新或切换聊天后继续处理。楼层号、普通勾选项、搜索条件和界面展开状态只在当前页面中保留，刷新后清空。

## 临时 IF 支线

- **开始支线**：选一条开场词，工具箱会把它作为 user 消息交给酒馆原生聊天。当前预设、世界书、角色卡、主接口和流式设置都由酒馆正常处理。
- **继续对话**：直接使用酒馆聊天框，可连续生成任意多轮。每个聊天同时只能有一条进行中的支线，不支持嵌套。
- **收藏并删除支线**：把支线内的 user 与 assistant 楼层完整保存到收藏夹，删除聊天末尾的整条支线，并还原开始前的聊天变量和全局变量。
- **仅删除支线**：不收藏，只删除整条支线并还原开始前变量。
- **保留为主线**：保留全部楼层和当前变量，只移除工具箱的支线标记。

收藏夹只保存消息原文与发言者，支持跨角色卡原文阅读、复制、TXT 导出、改名和删除；阅读不会重新执行角色卡正则或 HTML，收藏内容也不会再次注入主聊天。

删除支线会把全局变量也恢复到开始支线时的状态；支线进行期间如切到其他聊天，请避免修改同名全局变量。

## 安装

1. 在 SillyTavern 顶部打开“扩展”（Extensions）。
2. 选择“安装扩展”（Install Extension）。
3. 粘贴仓库地址：`https://github.com/c09222364-boop/Chat-toolbox`
4. 完成安装后刷新 SillyTavern。
5. 从三条杠菜单底部打开“聊天工具箱”。

扩展的各项功能可以在 Extensions 设置中单独开关。

## 使用建议

- 查找替换时先查找并逐项确认，完成后再点击“保存修改”。
- 世界书和预设条目在工具箱中编辑后，需要点击对应的保存按钮才会写入文件。
- 建立 IF 支线前可先用“填入聊天框”检查或修改开场词，再自行发送。
- EPUB 正文标签填写 `content` 时，会读取每层 `<content>...</content>` 内的文字。
